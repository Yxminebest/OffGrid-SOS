# รุ่น 0.9.9+30 — ส่งระหว่างเครื่องก่อนคลาวด์

2 พฤศจิกายน 2569

แชทข้อความ รูป วิดีโอ ตำแหน่ง และ SOS ใช้คิวและประวัติในเครื่อง ส่งโดยตรงผ่าน Bluetooth/Nearby เมื่อมีเส้นทางถึงผู้รับ ไม่รออินเทอร์เน็ตหรือการอัปโหลดคลาวด์

- ยกเลิกช่วงรอ cloud-first 8 วินาทีของไฟล์แนบจากรุ่น 29 รวมคิวรุ่นเก่าที่มี field cloudFirstUntil
- คงการเข้ารหัส การตรวจ hash ไฟล์ การยืนยันรับจากปลายทาง การส่งต่อผ่าน nodes และ retry เมื่อเชื่อมกลับ
- คลาวด์เป็นช่องทางเสริมและที่สำรองเมื่อออนไลน์ การบันทึกคลาวด์ไม่ถือว่าผู้รับ Bluetooth ได้รับไฟล์แล้ว
- คงการลดงานซ้ำและหน้าเล่นวิดีโอจากรุ่น 29

ชุดทดสอบอัตโนมัติผ่าน 192 เคส (build/tests-v30.log) รวมไฟล์ผ่าน 3 nodes, คิวออฟไลน์, SOS, ตัวตนกู้ภัย และวิดีโอที่เริ่มส่งวิทยุทันทีแม้ผู้ส่งมีอินเทอร์เน็ต ผล static analysis และ build อยู่ใน build/analyze-v30.log และ build/apk-v30.log

การทดสอบอัตโนมัติจำลองเส้นทางวิทยุ ไม่ได้ยืนยันระยะสัญญาณ ความเร็ว หรือ codec บนโทรศัพท์จริง ต้องเปิด Bluetooth และอนุญาตสิทธิ์ที่ Android ขอทั้งสองเครื่อง แอปต้องทำงานอยู่หรือเปิดบริการรับข้อความเบื้องหลังไว้ การ force-stop หรือปิดวิทยุไม่สามารถรับข้อความได้
