## การใช้งาน

หน้าแชทมีรายการเดียว ค้นหาผู้ติดต่อ/ข้อความล่าสุด กรองยังไม่ได้อ่านได้ ไม่มีหัวข้อแชทธรรมดาหรือแชท Nearby แยกกัน
ปุ่มเริ่มแชทใช้ค้นหาคนใกล้ตัวหรือสมาชิก จาก SOS/ศูนย์กู้ภัย/ประวัติ/การแจ้งเตือนเปิดห้องเดียวกัน

ปุ่ม + ในห้องมี ถ่ายรูป / รูปภาพจากเครื่อง / ตำแหน่งของฉัน / วิดีโอจากเครื่อง / ถ่ายวิดีโอ
ภาพแสดงเต็มสัดส่วน ใช้พื้นที่แชทกว้างขึ้น แตะดูและซูมภาพได้ วิดีโอเล่นจากไฟล์ในเครื่อง
ข้อความตำแหน่งมีภาพถนนจริงจากชุดปทุมธานีที่ติดตั้งอยู่ ไม่โหลด map screenshot จากอินเทอร์เน็ต
ยังแสดงพิกัด เวลาเมื่อมี metadata ความคลาดเคลื่อน และคำเตือนพิกัดเก่า
ไฟล์สูงสุด 25 MB ทั้งสองช่องทาง กล้องวิดีโอกำหนดความยาวสูงสุด 30 วินาที หากเกินขนาดให้ถ่ายสั้นลง ไม่ค้างล็อกกล้องครั้งต่อไป

## การส่งและความคงทนของข้อมูล

- คิววิทยุเข้ารหัสและส่งหลายทอดเดิมยังทำงาน พร้อม ACK และไฟล์ hash verified
- บันทึกก่อนส่ง ผู้ติดต่อที่เคยบันทึกเปิด/เขียนข้อความได้แม้ออฟไลน์ เมื่อยังไม่มีช่องทางจะแสดงค้างส่ง
- ห้องสมาชิกที่เคยเปิดออนไลน์ หากภายหลังจับคู่ตัวตนบัญชีเดียวกันผ่านวิทยุ คิวที่ยังไม่ซิงก์ส่งผ่านคู่เชื่อมต่อได้
- สมาชิกที่มี session และอินเทอร์เน็ต: ข้อความวิทยุของตนเข้าสู่คิว cloud messages เดิม ใช้ ID เดิมและเวลาเดิม จึงยุบข้อความเดียวกันจากสองช่องทางใน UI ได้
- ไม่ส่งข้อความ incoming โดยปลอมเป็นผู้ส่งบน cloud ไม่มี service-role key ในแอป ใช้ sender/member RLS เดิม
- เก็บการจับคู่ device/member ID แยก owner ใช้ ID ที่คู่ซึ่งผู้ใช้อนุมัติส่งมา ไม่อ้างว่าเป็นการยืนยันบัญชีจาก server และไม่รวมจากชื่อหรือบทบาทกู้ภัย
- ประวัติและไฟล์เดิมยังอ่านได้ ไม่ล้าง DB; ลบข้อมูลบัญชีลบ binding ใหม่ด้วย
- แยก รับถึงเครื่องแล้ว / ส่งแล้วรอยืนยัน / ค้างส่ง / ซิงก์แล้ว และรวมสถานะรับแล้ว+ซิงก์แล้วได้
- ห้องที่กำลังอ่านปิดการแจ้งเตือนซ้ำของทั้ง device ID และ conversation ID; เข้าเบื้องหลังยังแจ้งเตือนได้
- กล้องกู้คืนผลหลัง Android ปิด process โดยจำ type และปลายทางเดิม พร้อม UUID เดิม
- Worker ส่งงานไม่ซ้อน รวมเหตุเชื่อมต่อระหว่างทำงานเป็นรอบถัดไปจำนวนจำกัด และตรวจ owner/session ก่อนส่งต่อ

## ขอบเขต

Guest ติดต่อผ่านวิทยุได้โดยไม่สมัคร ส่วนส่งผ่านเซิร์ฟเวอร์ต้องเป็นสมาชิกที่เข้าสู่ระบบและทราบบัญชีปลายทาง
หากไม่มีอินเทอร์เน็ตและไม่มีเส้นทางวิทยุถึงผู้รับ ข้อความจะรอในเครื่อง ไม่แสดงว่าผู้รับได้รับแล้ว
แผนที่ครอบคลุมปทุมธานีตามชุดข้อมูลเดิม ไม่มีการรับประกันระยะวิทยุหรือความแม่นยำ GPS จากผลจำลอง
ต้องอัปเดตแอปทั้งสองเครื่องและทดสอบวิทยุจริง 2–3 เครื่อง รวม cloud session จริงก่อนส่งงาน
