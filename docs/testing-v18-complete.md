# Checklist ทดสอบรับงานรุ่น 0.8.0+18

ทุกข้อยังรอบันทึกผลจริง ไม่ใช่หลักฐานว่าผ่านแล้ว
Galaxy A03s และ OPPO A3s ติดตั้งรุ่น 18 แล้ว; เครื่องที่สามต้องอัปเดตรุ่นเดียวกัน

วิธีบันทึกแต่ละข้อ: ผ่าน/ไม่ผ่าน/ยังไม่ได้ทดสอบ + เครื่อง/Android + บัญชี/บทบาท + โหมดวิทยุ + เวลา + ภาพหรืออาการ
แชท/สื่อ/ตำแหน่งและคิวต้องลองทั้ง A→B และ B→A ใน Nearby และ Bluetooth โดยตรง
ใช้บัญชีทดสอบสำหรับเปลี่ยนอีเมล รหัสผ่าน ลบบัญชี และตรวจสิทธิ์

## เตรียมและการเปิดแอป

- [ ] T001 Galaxy และ OPPO แสดงรุ่น 0.8.0+18; เครื่องที่สามต้องเป็นรุ่นเดียวกัน
- [ ] T002 อัปเดตทับแล้วบัญชี ประวัติข้อความ SOS และไฟล์เดิมยังอยู่
- [ ] T003 ปิดแอปจากหน้าแชท/SOS/โปรไฟล์ แล้วเปิดใหม่: เริ่มหน้าหลัก
- [ ] T004 กลับจากกล้อง/ตัวเลือกไฟล์: กลับงานเดิมได้ ไม่เสียรูปหรือข้อความที่กำลังทำ
- [ ] T005 เปิดแอปตั้งแต่ไม่มีอินเทอร์เน็ต: Guest และตัวตนเดิมเข้าได้ ไม่โหลดค้าง
- [ ] T006 ปิด–เปิดเครื่องแล้วเปิดแอป: ข้อมูลและคิวเดิมยังอยู่; เริ่มบริการใหม่ได้

## สิทธิ์และการเชื่อมต่อสองเครื่อง — ทดสอบทั้ง Nearby และ Bluetooth โดยตรง

- [ ] T007 ปิด mobile data, hotspot และตัดจาก Wi-Fi router/AP ทั้งสองเครื่อง; เปิดวิทยุที่ใช้และ Location
- [ ] T008 ให้สิทธิ์ตำแหน่ง/Bluetooth/Nearby ตามที่ Android แต่ละรุ่นร้องขอ: ค้นหาและเชื่อมได้
- [ ] T009 ปฏิเสธสิทธิ์แล้วลองใช้งาน: มีคำอธิบาย ไม่แครช; ให้สิทธิ์ใหม่แล้วทำงานได้
- [ ] T010 ค้นหาสองเครื่อง: ชื่อถูกต้อง ไม่แสดงสมาชิกทั่วไปเป็นหน่วยกู้ภัย
- [ ] T011 จับคู่และเทียบรหัสทั้งสองฝั่ง: อนุมัติแล้วเชื่อมต่อสำเร็จ
- [ ] T012 ปฏิเสธหรือยกเลิกจับคู่: ไม่เชื่อมเอง; ขอใหม่ได้
- [ ] T013 หยุดค้นหา/เชื่อมต่อ: สถานะหยุดถูกต้อง; เปิดใหม่แล้วเชื่อมได้
- [ ] T014 ปิด Bluetooth หรือวิทยุที่กำลังใช้: แสดงหลุด; เปิดกลับแล้วเชื่อมและส่งต่อได้
- [ ] T015 ปิดวิทยุ Wi-Fi แล้วใช้ Bluetooth โดยตรงตามขั้นตอนในแอป: รับส่งได้โดยไม่มีเน็ต
- [ ] T016 เปิดแอปใหม่หลังเคยเปิดวิทยุ เทียบกับหลังเคยกดหยุดเอง: คืนโหมดถูกต้อง ไม่เปิดแทนเมื่อสั่งหยุด

## แชทรวมและข้อความ — ทำ A→B และ B→A ในแต่ละโหมดวิทยุ

- [ ] T017 เปิดจากแท็บแชท/Nearby/SOS: ไปหาคนเดิมและประวัติห้องเดียวกัน
- [ ] T018 ส่งไทย อังกฤษ ตัวเลข อีโมจิ และหลายบรรทัด: เนื้อหาครบ ไม่เพี้ยน
- [ ] T019 ส่งหลายข้อความติดกันและส่งพร้อมกันสองฝั่ง: ไม่หาย ไม่ซ้ำ ลำดับ/เวลาสมเหตุผล
- [ ] T020 กดส่งซ้ำเร็ว ๆ: ไม่สร้างสำเนาของการส่งเดียวกันโดยผิดพลาด
- [ ] T021 ส่งข้อความว่าง/ช่องว่างล้วน: ไม่ส่ง; เกิน 4,000 ตัวอักษร: แจ้งข้อผิดพลาดและไม่ล้างเนื้อหาทิ้ง
- [ ] T022 รับข้อความโดยยังไม่เปิดห้อง แล้วปิดเน็ต/เปิดแอปใหม่: อ่านข้อความที่ได้รับแล้วได้
- [ ] T023 ใช้ชื่อแสดงผลเหมือนกันกับคนละบัญชี: ต้องไม่รวมเป็นคนเดียวกัน
- [ ] T024 ชื่อหัวห้องและบทบาทของคู่สนทนาถูกต้อง; สมาชิกทั่วไปต้องไม่ขึ้นว่าแชทกับหน่วยกู้ภัย

## กล้อง รูป และวิดีโอ — ทำสองทิศทางและทั้งสองโหมดวิทยุ

- [ ] T025 ถ่ายรูปจากกล้องแล้วส่งออฟไลน์: อีกเครื่องได้รับและเปิดได้
- [ ] T026 เลือกรูปจากเครื่องแล้วส่งออฟไลน์: รูปตรงกับต้นฉบับและสัดส่วนถูกต้อง
- [ ] T027 แตะรูป: ดูขนาดใหญ่และซูมได้ ไม่เห็นแค่ชื่อไฟล์หรือภาพเล็กจนดูไม่ได้
- [ ] T028 เลือกวิดีโอจากเครื่อง: ส่งครบและเล่นภาพ/เสียงได้
- [ ] T029 ถ่ายวิดีโอจากกล้อง: ส่งและเล่นได้; ตรวจข้อจำกัดบันทึกไม่เกิน 30 วินาที
- [ ] T030 ยกเลิกกล้อง/ตัวเลือกสื่อ: ไม่ส่งไฟล์เปล่า ไม่ค้าง ไม่สร้างข้อความซ้ำ
- [ ] T031 ปฏิเสธสิทธิ์กล้อง: แจ้งวิธีแก้; อนุญาตแล้วกลับมาใช้งานได้
- [ ] T032 ส่งไฟล์ใกล้ 25 MB และเกิน 25 MB: ไฟล์ที่รองรับส่งได้; เกินขนาดแจ้งชัดเจน
- [ ] T033 ตัดลิงก์กลางส่งรูป/วิดีโอแล้วเชื่อมใหม่: ส่งต่อจนไฟล์ครบ เปิดได้ ไม่แสดงรับสำเร็จก่อนครบ
- [ ] T034 รับไฟล์เสร็จแล้วปิดเน็ต/ปิดเปิดแอป: ไฟล์ยังเปิดได้จากเครื่อง

## ตำแหน่งและแผนที่ออฟไลน์

- [ ] T035 แชร์ตำแหน่งจากแชท: ผู้รับเห็นพิกัด เวลา ค่าคลาดเคลื่อน และคำเตือนพิกัดเก่าตามจริง
- [ ] T036 เปิดตำแหน่งจากแชทและ SOS: เปิดแผนที่ภายในแอป
- [ ] T037 ไม่ต่อเน็ตตั้งแต่เปิดแอป: ถนนและชื่อสถานที่ปทุมธานียังแสดงจากข้อมูลติดตั้ง
- [ ] T038 ซูม/เลื่อน/กลับไปหมุด: หมุดของฉันและเป้าหมายแยกชัด ตำแหน่งไม่สลับ
- [ ] T039 ยืนกลางแจ้งเทียบจุดสังเกตจริงและรอ GPS: พิกัดสมเหตุผล พร้อมวง/ค่าคลาดเคลื่อนตามจริง
- [ ] T040 อยู่กับที่แล้วกดหา GPS ซ้ำหลายครั้ง: บันทึกการแกว่ง; ไม่ทำให้ดูแม่นยำกว่าค่าที่ GPS รายงาน
- [ ] T041 ปิด Location/ปฏิเสธสิทธิ์/อยู่ในอาคาร: แจ้งหาตำแหน่งไม่ได้หรือพิกัดเก่า ไม่อ้างว่าเป็นพิกัดสด
- [ ] T042 คัดลอกพิกัด: ค่าตรงกับหมุดและค่าที่ผู้ส่งส่งมา
- [ ] T043 ทดสอบบริเวณขอบ/นอกพื้นที่แผนที่: ไม่แครช และไม่อ้างว่ามีข้อมูลถนนทั่วประเทศ

## SOS ผู้ประสบภัย

- [ ] T044 เลือกเหตุฉุกเฉิน เช่น หลังคา/ชั้นสอง/ขาดน้ำ/ต้องการยา/ผู้ป่วยหนัก โดยไม่พิมพ์: ส่งเหตุที่เลือกได้
- [ ] T045 เลือกหลายเหตุและเพิ่มข้อความ: เนื้อหาที่ผู้รับเห็นครบและตรงกัน
- [ ] T046 เปิด SOS ขณะไม่มีเน็ต: บันทึกลงเครื่อง และอีกเครื่องที่เชื่อมอยู่เห็นสถานะสีแดง
- [ ] T047 เปิด SOS ก่อนมีคู่เชื่อมต่อ: บอกว่ายังรอส่ง; เชื่อมภายหลังแล้วส่งได้
- [ ] T048 ค้นหาเครื่องที่เปิด SOS ก่อนจับคู่: เห็นประกาศ; รายละเอียด/พิกัดรับหลังเชื่อมตามสิทธิ์
- [ ] T049 แตะการ์ด SOS: เข้าห้องสนทนาผู้แจ้งถูกคน; ดูรายละเอียดและแผนที่ได้
- [ ] T050 แก้ข้อความ/เหตุ/พิกัดของ SOS ที่กำลังเปิด: อีกเครื่องได้รับสถานะล่าสุด ไม่เพิ่มเคสซ้ำผิดพลาด
- [ ] T051 ปิด SOS ขณะเชื่อมอยู่: อีกเครื่องเลิกแสดงว่าเคสยัง active
- [ ] T052 ปิด SOS ตอนหลุด แล้วเชื่อมใหม่/เปิดแอปใหม่: เคสเก่าไม่กลับมา active
- [ ] T053 ประวัติ SOS อ่านออฟไลน์ได้ แยกกำลังขอ/ปิดแล้ว และสถานะซิงก์ถูกต้อง

## หน่วยกู้ภัยและการอนุมัติ — ใช้บัญชีทดสอบ

- [ ] T054 สมาชิกทั่วไป/Guest เปิดสถานะกู้ภัยที่ยืนยันแล้วไม่ได้ และไม่ถูกประกาศเป็นกู้ภัยสีน้ำเงิน
- [ ] T055 ส่งคำขอสิทธิ์พร้อมข้อมูล/เอกสารที่ถูกต้อง: บันทึกได้และเห็นสถานะรอตรวจ
- [ ] T056 ข้อมูลไม่ครบ/ชนิดไฟล์ไม่รองรับ/เอกสารเกิน 10 MB: แจ้งชัดเจน ไม่ส่งแบบข้อมูลเสีย
- [ ] T057 Admin อนุมัติขณะผู้ขอออนไลน์: มีการแจ้งผล โปรไฟล์และประวัติอัปเดต และรับใบรับรองใหม่ได้
- [ ] T058 Admin ปฏิเสธ: เห็นเหตุผลและประวัติ; ไม่มีสิทธิ์เปิดกู้ภัย
- [ ] T059 บัญชีอนุมัติแล้ว: สถานะหน้าคำขอไม่ขัดกับโปรไฟล์หรือทำให้เข้าใจว่ายังไม่เคยสมัคร
- [ ] T060 รับสิทธิ์/ใบรับรองออนไลน์ก่อน แล้วปิดเน็ต: เปิดกู้ภัยได้ภายในอายุใบรับรอง
- [ ] T061 หลังจับคู่และตรวจหลักฐานสำเร็จ: อีกเครื่องเห็นกู้ภัยสีน้ำเงิน; จดเวลาที่ใช้จริง
- [ ] T062 หยุดปฏิบัติหน้าที่และเปิดใหม่: สถานะบนอีกเครื่องเปลี่ยนตาม; UI ปกติไม่กลายเป็นน้ำเงินทั้งแอป
- [ ] T063 ปิดโหมดตอนหลุด แล้วเชื่อม/เปิดแอปใหม่: สถานะเปิดเก่าไม่กลับมาเอง
- [ ] T064 รับ SOS หลายคน: จำนวนเคส ผู้แจ้ง เนื้อหา พิกัด และแชทไม่สลับกัน
- [ ] T065 โปรไฟล์กู้ภัยเปิดดูประวัติคำขอ/ผลอนุมัติ และประวัติเคสที่ได้รับได้แม้ออฟไลน์

## คิว สถานะส่ง และข้อมูลในเครื่อง

- [ ] T066 ตัดการเชื่อมต่อแล้วส่งข้อความ/รูป/วิดีโอ/ตำแหน่ง: อยู่ในคิว ไม่หาย และแสดงค้างส่ง
- [ ] T067 ปิด–เปิดแอประหว่างค้างส่ง: คิวยังอยู่; เชื่อมใหม่แล้วส่งครบโดยไม่ซ้ำ
- [ ] T068 ตรวจสถานะค้างส่ง → รับถึงเครื่อง/ส่งแล้ว → ซิงก์แล้วตามเหตุการณ์จริง
- [ ] T069 ขณะไม่มีอินเทอร์เน็ต: ต้องไม่อ้างว่าซิงก์คลาวด์สำเร็จ
- [ ] T070 วิทยุตัดก่อนปลายทางรับครบ: ต้องไม่แสดงรับถึงเครื่องก่อนมีหลักฐานรับจริง
- [ ] T071 เริ่มส่งให้หลายคนขณะ cloud ช้า/เข้าไม่ได้: วิทยุของคนอื่นไม่ถูก HTTP ขวาง
- [ ] T072 คิวที่ส่งแล้วเปิดแอปใหม่/เชื่อมหลายรอบ: ไม่ย้อนส่งเป็นข้อความใหม่
- [ ] T073 พื้นที่เครื่องเหลือน้อย: แจ้งบันทึก/รับไฟล์ไม่ได้ ไม่แสดงสำเร็จเท็จ (ใช้เครื่องทดสอบ ไม่เติมจนเครื่องใช้งานไม่ได้)

## สามเครื่อง A–B–C — ทดสอบเมื่อมีเครื่องที่สาม

- [ ] T074 เชื่อม A↔B และ B↔C โดยไม่มีลิงก์ตรง A↔C: ยืนยันเส้นทางผ่าน B จริง
- [ ] T075 A และ C ขอจับคู่ B ใกล้กัน: รหัส/คำขอไม่ทับหรืออนุมัติผิดเครื่อง
- [ ] T076 ส่งข้อความ A→C และ C→A: ถึงปลายทาง ไม่ไปเป็นข้อความส่วนตัวของ B
- [ ] T077 ส่งรูป วิดีโอ และตำแหน่ง A↔C: เปิดครบและมีการยืนยันรับจากปลายทาง
- [ ] T078 A เปิด/แก้/ปิด SOS: C ได้สถานะล่าสุด และตอบกลับ A ผ่าน B ได้
- [ ] T079 กู้ภัยเปิด/ปิดสถานะข้าม B: C เห็นสถานะตามจริงหลังยืนยันสิทธิ์
- [ ] T080 ตัด B กลางส่ง: A/C เห็นค้างส่ง; นำ B กลับและเชื่อมแล้วส่งครบ ไม่ซ้ำ
- [ ] T081 เปิดทุกลิงก์เป็นวง A–B–C–A: ไม่เกิดข้อความวนซ้ำหรือ SOS เพิ่มจำนวนไม่หยุด

## ออนไลน์ สมาชิก และกลับมาออฟไลน์

- [ ] T082 สมัครสมาชิก/ยืนยันอีเมล/เข้าสู่ระบบ: ใช้บัญชีจริงได้; รหัสผิดมีข้อความที่เหมาะสม
- [ ] T083 ลืมรหัสผ่านและลิงก์ตั้งรหัสใหม่: กลับเข้าแอปและเข้าสู่ระบบด้วยรหัสใหม่ได้
- [ ] T084 แก้ข้อมูลส่วนตัว/รูปโปรไฟล์: บันทึกและเปิดใหม่แล้วข้อมูลตรงกัน
- [ ] T085 เปลี่ยนอีเมล/รหัสผ่านตามขั้นตอนยืนยัน: บัญชีเดิมไม่สูญหาย (ใช้บัญชีทดสอบ)
- [ ] T086 ส่งข้อความ/สื่อออนไลน์แล้วตัดเน็ต: ข้อความที่บันทึกและไฟล์ที่ดาวน์โหลดครบยังอ่านได้

## ขอบเขตที่ต้องใช้ตัดสินผล

- ไม่มี Internet ไม่ได้แปลว่าปิดวิทยุทั้งหมด; ทดสอบโดยไม่ต่อ AP/hotspot และปิด mobile data
- GPS ในอาคารอาจคลาดเคลื่อน ต้องรายงานค่าจริง ไม่คาดหวังศูนย์เมตรหรือใช้ค่าที่แต่งขึ้น
- แผนที่ติดตั้งเฉพาะปทุมธานี ไม่มีเส้นทางนำทางเลี้ยวต่อเลี้ยว
- ระบบหลายทอดต้องมี B และเส้นทางอยู่ ไม่ใช่ B รับฝากไปส่งหลัง A หายไป
- ไม่คาดหวังข้อความเข้าระหว่าง force-stop; ต้องเปิดแอปใหม่
- สื่อ cloud ที่ไม่เคยดาวน์โหลดครบเปิดออฟไลน์ไม่ได้
- การสมัครใหม่/ยืนยันสมาชิก/อนุมัติกู้ภัย/รับใบรับรองครั้งแรกต้องออนไลน์; ใบรับรองหมดอายุยังแชท/SOS ได้แต่เปิดกู้ภัยที่ยืนยันไม่ได้
- ห้ามใช้ผลการติดตั้งสำเร็จแทนผลการทดสอบฟังก์ชัน
