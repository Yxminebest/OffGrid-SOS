# รุ่น 0.10.2+33 — ตอบกลับ แก้ไข ยกเลิกข้อความ

กดค้างที่ข้อความในห้องสนทนารวมเพื่อเปิดเมนู ตอบกลับและคัดลอกได้ ส่วนแก้ไขข้อความชนิด text และยกเลิกส่งจำกัดเฉพาะข้อความตัวเอง มีช่องอ้างอิงข้อความเหนือแป้นพิมพ์ที่ปิดได้ และหน้าต่างยืนยันก่อนยกเลิกส่ง รูป/วิดีโอ/พิกัดยกเลิกได้ แต่ไม่แปลงเนื้อหาสื่อเป็นข้อความด้วยเมนูแก้ไข

คำสั่งใช้ local persistence และ transport เดิม: เข้ารหัสผ่าน Bluetooth/Nearby เมื่อมีเส้นทาง และซิงก์ผ่าน public.messages เมื่อออนไลน์ ใช้ ID เดียวกันและไม่สร้างคำสั่งซ้ำในการ retry การแสดงผลตรวจผู้เขียน/ห้องก่อนเปลี่ยนข้อความ เรียงการแก้ไขตามเวลาของคำสั่งและใช้ ID ตัดสินเมื่อเวลาเท่ากัน ยกเลิกเป็นสถานะสุดท้ายที่ edit ภายหลังไม่ทำให้คืนกลับ

ตัวส่งหยุด media transfer ที่ยกเลิกและระงับคิวต้นฉบับ ตัวรับหยุดแสดง progress ของไฟล์จากผู้ส่งรายนั้นเมื่อได้รับคำสั่งยกเลิก คำสั่งที่ได้รับก่อนต้นฉบับเก็บไว้ประมวลผลกับประวัติภายหลังได้

## ขอบเขต

ต้องอัปเดตทั้งสองฝั่งเป็นรุ่น 33 ขึ้นไปเพื่ออ่านคำสั่งใหม่ รุ่นเก่าอาจแสดง content ที่เข้ารูปแบบเป็นข้อความธรรมดา ยังไม่ได้ทดสอบเมนูและวิทยุใหม่บนโทรศัพท์จริง การทดสอบข้างต้นเป็น unit/widget และ transport จำลอง

คำสั่งแก้ไข/ยกเลิกที่ค้างส่งมีผลอีกฝั่งเมื่อเชื่อมกลับ การยกเลิกไม่รับประกันว่าอีกฝ่ายยังไม่เคยอ่านหรือบันทึกสำเนาไว้ คำสั่งที่ส่งด้วยนาฬิกาย้อนเวลาก่อนเวลาข้อความต้นฉบับถูกปฏิเสธ และการแก้ไขข้ามหลายเครื่องในบัญชีเดียวกันยังไม่ได้ทำ conflict resolution แบบ logical clock
