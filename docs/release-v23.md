# 0.9.2+23 — กด SOS ค้าง 3 วินาทีและยืนยันลบบัญชีสองขั้น

- ปุ่ม SOS ต้องกดค้างต่อเนื่อง 3 วินาที มีวงความคืบหน้ารอบปุ่ม
- แตะสั้น/ปล่อยก่อนครบ/เลื่อนออกนอกปุ่ม/ระบบยกเลิกสัมผัส/พักแอป ยกเลิกการนับ ไม่ส่ง SOS
- ครบเวลาแล้วส่งหนึ่งครั้ง ไม่เปิดหน้ารายละเอียดตามการปล่อยนิ้วเดียวกัน; SOS ที่เปิดแล้วแตะเพื่อดูสถานะได้
- ตัดแถบคำอธิบายการเก็บในเครื่อง/ซิงก์ออกจากหน้าหลัก ลดคำอธิบายซ้ำใน SOS/แชท/Nearby คงสถานะค้างส่ง/รับแล้ว/ซิงก์และข้อผิดพลาดที่ต้องแก้
- ลบบัญชี: กรอกรหัสผ่าน → ยืนยัน → Supabase ตรวจรหัสผ่าน → หน้าสรุปบัญชีและข้อมูลที่จะลบ → ยืนยันลบถาวรอีกครั้ง
- รหัสผิดไม่ไปขั้นยืนยันสุดท้าย ยกเลิกขั้นสุดท้ายไม่เรียก delete-account ตรวจบัญชีปัจจุบันก่อนและหลังหน้าสรุป
- คงการตรวจรหัสผ่านซ้ำใน deleteMyAccount ก่อนเรียกเซิร์ฟเวอร์ ไม่ลดการตรวจสอบเดิม
- ไม่มีการลบบัญชีจริงระหว่างพัฒนา และไม่มีการเปลี่ยน backend ในรอบนี้

## หลักฐานตรวจ

การตรวจรหัสผ่านและลบบัญชีจริงต้องทดสอบด้วยบัญชีทดสอบออนไลน์ ไม่อ้างว่าผ่านจากผล UI
