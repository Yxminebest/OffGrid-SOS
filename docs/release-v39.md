# SOSBROO 0.10.8+39

## สิ่งที่เปลี่ยน

- เอาการ์ดการซิงก์คลาวด์ออกจากรายละเอียด SOS การซิงก์และคิวเก็บในเครื่องยังทำงานเดิม การ์ดนี้เป็นสถานะทางเทคนิค ไม่ใช่ใบตอบรับจากกู้ภัย สถานะรับถึงอุปกรณ์/ตอบรับความช่วยเหลือยังใช้ระบบเดิม
- เว้นระยะ 16 logical pixels ระหว่างการ์ดตำแหน่งล่าสุดกับปุ่มเปิดตำแหน่งบนแผนที่
- เปลี่ยนเมนูจากลบเฉพาะเครื่องนี้เป็นลบข้อความทุกเครื่อง เฉพาะข้อความที่บัญชีนี้เป็นผู้ส่ง รวมข้อความที่เคยยกเลิกส่งแล้ว คำสั่ง delete เก็บใน durable queue เดิม ผ่าน encrypted radio/relay หรือข้อความคลาวด์ตามเส้นทางที่มี
- ลบจะซ่อนกล่องข้อความจากแชททั้งสองฝั่ง ยกเลิกส่งยังคงแสดงกล่องข้อความที่ยกเลิก ผู้รับไม่สามารถส่งคำสั่งลบข้อความของผู้เขียนคนอื่นได้
- การลบเป็น terminal state: edit/retract ที่มาช้าไม่ทำข้อความกลับมา ตัดต้นฉบับออกจากรายการส่งซ้ำ แต่เก็บคำสั่งควบคุมไว้ และยกเลิกการส่ง/รับสื่อที่กำลังทำงานสำหรับข้อความนั้น
- เอาคำอธิบายใต้หัวข้อใน dialog ยืนยันลบออก เหลือหัวข้อกับปุ่มกลับ/ลบข้อความ

## ขอบเขตการลบ

ทั้งสองฝั่งต้องใช้รุ่น 39 หรือใหม่กว่าเพื่ออ่านคำสั่ง delete หากยังติดต่อกันไม่ได้ คำสั่งรอในเครื่องและจะมีผลที่เครื่องปลายทางเมื่อได้รับคำสั่ง อุปกรณ์ที่ใช้รุ่นเก่าอาจแสดงข้อความคำสั่งที่ไม่รู้จัก จึงควรอัปเดตทุกเครื่องก่อนใช้

การลบนี้นำข้อความออกจากประวัติแชทในแอป ไม่ใช่การรับรองว่าจะล้างทุกสำเนา เช่น ภาพหน้าจอ/ไฟล์ที่ผู้รับส่งออกหรือสำเนาสำรอง คำสั่งและข้อมูลสำหรับการส่งซ้ำ/ตรวจผู้เขียนยังอาจคงอยู่ในฐานข้อมูลเพื่อป้องกันการนำต้นฉบับกลับมา ระบบซ่อนข้อความเฉพาะเครื่องจากรุ่นก่อนยังเคารพรายการที่เคยซ่อนไว้ แต่ไม่มีเมนูสร้างการลบแบบนั้นใหม่ในรุ่นนี้
