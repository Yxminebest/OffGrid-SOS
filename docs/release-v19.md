# 0.8.1+19 — หน้าหลักและจัดการบัญชี

วันที่ 24 ตุลาคม 2569

- เอาปุ่มสลับธีมออกจากหน้าหลัก การเลือกธีมยังอยู่ในโปรไฟล์
- ตำแหน่งเดิมแสดงปุ่ม SOS สีแดงเมื่อ SOS เปิด หรือปุ่มกู้ภัยสีน้ำเงินเมื่อกำลังปฏิบัติหน้าที่ กดเพื่อเข้าหน้าสถานะนั้น ไม่มีโหมดทำงานก็ไม่แสดงปุ่ม หากเปิดทั้งคู่ให้ SOS สีแดงมีลำดับก่อน
- ปุ่ม SOS ใช้สถานะใน local DB และปุ่มกู้ภัยใช้สถานะของอุปกรณ์/เจ้าของปัจจุบัน ไม่ใช้เพียง role ว่ามีสิทธิ์กู้ภัย
- หน้าลบบัญชีเหลือช่องรหัสผ่านปัจจุบันและปุ่มยืนยัน ไม่ต้องพิมพ์ DELETE ปุ่มยืนยันปิดเมื่อยังไม่ได้กรอกรหัสผ่าน
- คง AuthService.verifyCurrentPassword ที่ตรวจผ่าน Supabase Auth ก่อนเรียก delete-account หากตรวจไม่ผ่านหรือไม่มีอินเทอร์เน็ต จะไม่เริ่มลบข้อมูลบัญชี
- เอา Account CRUD, คำอธิบายเทคนิค และ User ID ออกจากหน้าจัดการบัญชี
- เพิ่มส่วนรูปโปรไฟล์ ชื่อ อีเมล ปุ่มเปลี่ยนรูปและรีโหลดข้อมูล พร้อมสถานะกำลังโหลดและข้อความเมื่อผิดพลาด
- เปลี่ยนรูปได้จากแกลเลอรี/กล้อง อัปโหลดผ่าน avatars เดิม อัปเดตกลับหน้าโปรไฟล์และล้างแคชรูปเก่าหลังสำเร็จ
- ไม่มีการเปลี่ยน schema หรือ deploy backend ในรอบนี้

พักการรันชุดทดสอบและการทดสอบ/ติดตั้งบนโทรศัพท์ตามคำขอผู้ใช้ การตรวจ analyzer และประกอบ APK ไม่ใช่หลักฐานผ่านการทดสอบฟังก์ชันหรือการลบบัญชีจริง
