## บัญชีและบทบาท

| ผู้ใช้ | การเตรียม | ใช้งานเมื่อไม่มีเน็ต |
|---|---|---|
| Guest | สร้างชื่อในเครื่อง | แชท/ไฟล์/ตำแหน่ง/SOS/แผนที่ |
| สมาชิก | สมัคร/เข้าสู่ระบบออนไลน์ แล้วรับใบรับรองอุปกรณ์ | ฟีเจอร์ข้างต้น + ตัวตนบัญชีที่ตรวจสอบได้ภายในอายุใบรับรอง |
| กู้ภัย | Admin อนุมัติ แล้วให้แต่ละเครื่องรับใบรับรองใหม่ออนไลน์ | เปิด/ปิดสถานะกู้ภัยสีน้ำเงิน รับ SOS เข้าแชท และดูประวัติที่เก็บในเครื่อง |

เปิดวิทยุ Wi-Fi/Bluetooth และ Location/สิทธิ์ที่ Android ขอ ไม่ต้องต่อ hotspot หรือมี Internet สำหรับ D2D
หลังจับคู่ให้ตรวจรหัสทั้งสองเครื่องให้ตรงกัน ตัวกลาง B ต้องเปิดแอป/วิทยุและยังมีเส้นทางสำหรับ A–B–C

## สคริปต์เดโม 7–10 นาที

1. นาที 0–1: ปัญหา/กลุ่มผู้ใช้ เปิดแอปที่หน้าหลัก อธิบายข้อมูลในเครื่องกับการซิงก์
2. นาที 1–2: แสดง mobile data ปิด/ไม่เชื่อม AP บน A และ B เปิด Wi-Fi radio/Bluetooth แล้วจับคู่
3. นาที 2–4: ห้องแชทเดียว ส่งข้อความ ถ่ายรูป เลือกรูป ถ่าย/เลือกวิดีโอ และแชร์พิกัด เปิดภาพใหญ่/แผนที่ปทุมธานีในแอป
4. นาที 4–5: A เลือกเหตุฉุกเฉินแล้วเปิด SOS → B เห็นแดง แตะเข้าห้องเดิม และปิด SOS ให้เห็นสถานะเปลี่ยน
5. นาที 5–6: บัญชี B ที่ได้รับสิทธิ์และใบรับรองแล้วเปิดโหมดกู้ภัย → A เห็นสีน้ำเงินที่ยืนยันแล้ว และปิดโหมด
6. นาที 6–8: เพิ่ม C ใช้ B เป็นทางผ่าน ส่ง A→C แล้วตัด B ให้เห็นค้างส่ง คืนการเชื่อมต่อให้ส่งต่อสำเร็จ (ต้องพิสูจน์ A–C ไม่มีลิงก์ตรงจริง)
7. นาที 8–9: กลับมาออนไลน์ แสดงคิวซิงก์และประวัติเดียว ไม่เกิดข้อความซ้ำ
8. นาที 9–10: เปิดใหม่เริ่มหน้าหลัก อ่านประวัติ/ไฟล์ที่ดาวน์โหลดแล้วเมื่อออฟไลน์ และอธิบายขอบเขต GPS/ระยะ/ใบรับรองตามจริง

## หลักฐานที่ค่อยเก็บเมื่อกลับมาทดสอบ

- ยี่ห้อ/Android/รุ่น APK/บทบาท/เวลาของทุกเครื่อง
- ภาพไม่มี Internet, รหัสจับคู่, สถานะแดง/น้ำเงิน, การรับข้อความ/ไฟล์/ตำแหน่ง
- บันทึก A–B–C และการตัดตัวกลาง พร้อมผลคิว/ACK/ไฟล์ครบ
- ผลขอใบรับรองสมาชิกจริงและกรณีใบรับรองไม่ถูกต้อง/หมดอายุ
- ผลกลับมาออนไลน์/Storage/ซิงก์ และการสลับบัญชีไม่เห็นประวัติผู้อื่น
- ผลชุดทดสอบรุ่น 18 ที่ยังไม่ได้รัน

## การดูแล key

ห้ามนำ issuer seed หรือ service-role key ลง APK/README/GitHub ใช้ public verification key ที่ฝังในแอปเท่านั้น
หากย้าย Supabase project หรือเปลี่ยน issuer ต้องเตรียม trust-anchor rotation และ APK ใหม่ก่อนใช้งาน ไม่ดาวน์โหลด public key จากคู่สนทนามาแทนโดยอัตโนมัติ
APK ชุดนี้ใช้ package/ใบรับรองติดตั้งเดิมเพื่ออัปเดตจากเครื่องทดสอบเดิม ก่อนเผยแพร่ร้านแอปต้องกำหนด application ID และกุญแจเผยแพร่ที่เจ้าของโครงการดูแลเอง
