# 0.9.3+24 — การแจ้งเตือน SOS และความชัดเจนของการเชื่อมต่อ

รายละเอียดเทียบอาจารย์ใน [teacher-comparison-v24.md](teacher-comparison-v24.md)

- ปุ่ม SOS ค้าง 3 วินาที วงแสดงความคืบหน้า และยืนยันลบบัญชีสองขั้นคงเดิม
- หน้าหลักบอก Bluetooth โดยตรง/Nearby Connections จากลิงก์ที่เชื่อมจริง
- SOS มีช่องแจ้งเตือนแยก เสียง/สั่นตามการตั้งค่า Android ID ต่อเคสไม่สร้างรายการซ้ำ ยกเลิกเมื่อได้รับสถานะหยุด
- แตะแจ้งเตือน SOS เปิดห้องผู้แจ้ง โดยตรวจเจ้าของบัญชีและ inbox ก่อนนำทาง
- แถบรับไฟล์ในแชทมีพื้นที่คงที่รองรับการขยายอักษร ไม่ดันช่องพิมพ์ขึ้นลง
- ยังต้อง native E2E บนโทรศัพท์สำหรับเสียง การแตะแจ้งเตือน และการส่งวิทยุจริง
