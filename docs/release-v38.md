# SOSBROO 0.10.7+38

## สิ่งที่แก้ตามภาพ

- นำคำอธิบายใน dialog ยกเลิกส่งข้อความออก คงหัวข้อและปุ่มยืนยัน/กลับ
- นำคำโปรยใต้คำทักทายในหน้าหลักออก และนำข้อความกดค้าง 3 วินาทีออก
- ลดขนาดปุ่ม SOS จาก 196 เป็น 172 logical pixels เปลี่ยนเวลากดค้างเป็น 1 วินาที เมื่อครบเวลาจะบันทึกคำขอในเครื่องก่อน แล้วเปิดหน้ารายละเอียด SOS ทันที งาน GPS/ส่งวิทยุทำเบื้องหลังตามเดิม การแตะสั้นหรือปล่อยก่อนครบเวลาไม่เปิดคำขอ และการปล่อยนิ้วหลังครบเวลาไม่เปิดหน้าซ้ำ
- หน้าโปรไฟล์ส่ง AppUser ที่บันทึกแล้วกลับไป HomeShell ทั้งการแก้บัญชี เปลี่ยนรูป และรีเฟรช HomeShell ปรับข้อมูลที่ใช้ทุกแท็บและอัปเดตชื่อใน mesh session เดิมโดยไม่ออกจากระบบ
- เปลี่ยนรายการแจ้งเตือนเป็นสวิตช์เสียงแจ้งเตือนข้อความ ค่าเก็บใน Android SharedPreferences และอ่านเมื่อเปิดโปรไฟล์/กลับเข้าแอป ปิดเสียงแล้วยังคงรับข้อความ/แสดงแจ้งเตือน และไม่ปิดบริการรับข้อความเบื้องหลัง
- Android เลือก notification channel แบบมีเสียงหรือไม่มีเสียงตามสวิตช์ ทั้งข้อความและ SOS ช่องเงียบตั้ง sound เป็น null เพื่อรองรับ Android 8+ ที่กำหนดเสียงแยกตาม channel; Android รุ่นก่อนใช้ defaults ที่ไม่มีเสียง การเปิดเสียงยังขึ้นกับสิทธิ์แจ้งเตือนและการตั้งเสียง/DND ของระบบปฏิบัติการ
- นำคำอธิบายใต้รับข้อความเบื้องหลังและสิทธิ์ของแอปออก
- เปลี่ยนคนใกล้ตัวเป็นบุคคลใกล้เคียงในเมนูเริ่มแชทและข้อความแนะนำ
