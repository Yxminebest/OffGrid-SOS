# SOSBROO 0.10.9+40

## เมนูข้อความ

เมนูจากปุ่มจุดสามจุดและการกดค้างใช้ชุดเดียวกัน เหลือ 4 รายการตามลำดับ:

1. ยกเลิกส่งข้อความ — ผู้ส่งยกเลิกเนื้อหาและหยุดคิว/การโอนไฟล์ โดยยังคงกล่องยกเลิกข้อความ
2. ลบข้อความทุกเครื่อง — ผู้ส่งนำกล่องข้อความออกจากแชทของทั้งสองฝั่ง รวมกล่องที่เคยยกเลิกแล้ว ใช้ durable delete จากรุ่น 39
3. แก้ไขข้อความ — ข้อความตัวอักษรแก้เนื้อหา รูป/วิดีโอแก้คำบรรยาย ตำแหน่งแก้ข้อความประกอบ โดยคงชนิดข้อความ ไฟล์เดิม และพิกัดจริงเดิม ไม่เปลี่ยนรูป/วิดีโอหรือย้ายหมุดด้วยคำสั่งแก้ข้อความ
4. ตอบกลับ — อ้างอิง ID ข้อความเดิม

นำคัดลอกออกจากเมนูข้อความ ปุ่มแก้ไข ลบ และยกเลิกเปิดใช้เฉพาะข้อความที่ส่งเอง ข้อความรับจากอีกฝ่ายแสดงรายการเดิมแต่ปิดคำสั่งเปลี่ยนข้อมูลเหล่านั้น เหลือตอบกลับที่กดได้ ข้อความที่ยกเลิกแล้วตอบกลับ/แก้ไข/ยกเลิกซ้ำไม่ได้ แต่ผู้เขียนยังลบกล่องยกเลิกจากทุกเครื่องได้

## ออนไลน์และออฟไลน์

การแก้คำบรรยายใช้ edit command เดิมผ่านคิวที่เก็บในเครื่อง การลบและยกเลิกใช้คำสั่งของผู้เขียนเดิม ทุกคำสั่งส่งผ่าน encrypted radio/relay หรือคลาวด์ได้ เมื่อยังติดต่อไม่ได้จะแสดงผลในเครื่องและรอส่งตามคิว เมื่อรับการแก้คำบรรยายแล้วจะแสดงคำบรรยายใหม่พร้อมแก้ไขแล้ว โดยไม่ส่งไฟล์สื่อซ้ำ

ควรอัปเดตทั้งสองฝั่งเป็นรุ่น 40 เพื่อรองรับการแก้คำบรรยายสื่อ รุ่นก่อนอาจไม่ใช้ edit กับข้อความที่เป็นรูป/วิดีโอ การลบยังมีขอบเขตการลบในแชทและการเก็บคำสั่งเพื่อป้องกันข้อมูลกลับมาตาม release-v39 ไม่รับรองการลบสำเนาที่ผู้รับส่งออกนอกแอป
