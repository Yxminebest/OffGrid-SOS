# Release 0.9.5+26 — ลดข้อความบนหน้าจอ

ลบข้อความ/ส่วนที่ผู้ใช้ทำเครื่องหมายสีแดงจากภาพอ้างอิง 17 ภาพ:

- จัดการบัญชี: คำอธิบายข้อมูลส่วนตัว อีเมล รหัสผ่าน รีโหลด และลบบัญชี รวมถึงรายการกู้คืนประวัติ Nearby จากคลาวด์
- โปรไฟล์: คำอธิบายประวัติเคสและข้อความท้ายหน้า
- ประวัติกู้ภัย: คำอธิบายส่วนบนทั้งหน้าประวัติเคสและประวัติการขอสิทธิ์
- แชท: คำอธิบายหัวหน้าและตัวเลือกสร้างบทสนทนา
- Nearby: คำอธิบายหัวหน้า สถานะประกาศตัว คำแนะนำ Wi-Fi/Bluetooth การเชื่อมต่อสามขั้นตอน และคำอธิบายเมื่อไม่พบอุปกรณ์
- หน้าหลัก: รายละเอียดใต้เมนูข้อความ ศูนย์กู้ภัย แผนที่ และข้อความท้ายหน้า
- ศูนย์กู้ภัย: ข้อความบนแถบด้านบน ใบรับรอง คำแนะนำเปิดรับเคส เมนูประวัติสองรายการ ข้อจำกัดท้ายหน้า และคำอธิบายท้ายรายละเอียด SOS
- แผนที่: คำอธิบายท้ายหน้า

ประวัติกู้ภัยยังเปิดจากหน้าโปรไฟล์ได้ ไม่ลบข้อมูลประวัติ ไม่เปลี่ยนการตรวจรหัสผ่าน/ยืนยันลบบัญชี และไม่เปลี่ยนการส่ง SOS แชท หรือการซิงก์
