# รุ่น 0.10.3+34 — SOS หลังพักหน้าจอและการส่งไฟล์

## สิ่งที่แก้

- หน้าหลักใช้ stream SOS เดิมระหว่าง rebuild ไม่เปิด query ใหม่ตาม progress ของไฟล์ และใช้สถานะ SOS ของเจ้าของจาก local DB ระหว่างรอ snapshot แรก กลับจากพักหน้าจออ่านสถานะในเครื่องก่อนฟื้นวิทยุหรือคลาวด์ การหยุด SOS ล้างสถานะสำรองด้วย
- รายการ Nearby และจำนวนเครื่องรวม endpoint ที่มี device ID เดียวกัน เลือกตัวที่เชื่อมต่อและตรวจตัวตนแล้วก่อน ไม่รวมบุคคลเพียงเพราะชื่อเหมือนกัน เพิ่ม stable hint ในการประกาศและไม่เชื่อม endpoint ซ้ำที่เป็นเครื่องเดียวกัน ล้างรายการค้นพบที่ไม่เชื่อมและเก่าเกิน 30 วินาที
- ข้อมูลประกาศค้นหาไม่ใช่สิทธิ์กู้ภัย แถบสีน้ำเงินยังต้องมีใบรับรองที่ตรวจผ่านและเปิดปฏิบัติหน้าที่
- สถานะใต้ชื่อห้องแชทเหลือ ออนไลน์/ออฟไลน์ ตามช่องทางอินเทอร์เน็ตที่แอปใช้ได้ ไม่ใช้เป็นหลักฐานว่าอีกฝ่ายกำลังอ่านข้อความ ออฟไลน์ยังส่งผ่านวิทยุได้
- ส่งไฟล์ด้วยหน้าต่างสูงสุด 4 ส่วน ส่วนละ 12 KB เปิดไฟล์อ่านครั้งเดียวต่อรอบส่ง ลดการ fsync ทุกส่วน รองรับส่วนที่มาถึงสลับลำดับด้วย buffer จำกัดขนาด และ ACK หลังเขียนส่วนไฟล์ตามลำดับ ตรวจ SHA-256 และบันทึก DB ก่อนยืนยันไฟล์สำเร็จ การแจ้งเตือน OS ไม่ขวาง ACK สุดท้าย
- ยังคงการส่งต่อจากขนาดไฟล์จริงหลังหลุด การยกเลิก การแยกเจ้าของและคู่สนทนา และการให้ SOS/คำสั่งสำคัญแซงส่วนไฟล์
- แชร์ตำแหน่งในแชทใช้พิกัดที่เตรียมไว้หรือ GPS fix แรก (รอ stream สูงสุด 8 วินาที) แทนรอการเก็บตัวอย่างทั้งหมด มี fallback พิกัดเดิมพร้อมเวลาและความคลาดเคลื่อนตามจริง ไม่แต่งค่าความแม่นยำ
- หน้าหลักเหลือ 3 ทางลัด: บุคคลใกล้เคียง ข้อความ ศูนย์กู้ภัย เอาทางลัดแผนที่ปทุมธานีและข้อความเชื่อมต่อที่ระบุออก แผนที่ในข้อความตำแหน่ง/SOS ยังใช้ได้
- เอาการ์ดข้อความ Nearby ด้านล่างออก รวมทั้งแถวกู้ภัยซ้ำกับรายชื่อเครื่อง โปรไฟล์เอาเมนูตรวจความพร้อมออฟไลน์และข้อความรองตามที่ระบุออก ลบไฟล์หน้าตรวจความพร้อมที่ไม่มีผู้เรียกใช้แล้ว

## สิ่งที่ยังต้องยืนยันด้วยโทรศัพท์

ผลข้างต้นเป็น unit/widget และ transport จำลอง ยังไม่ได้ติดตั้งหรือวัดเวลา/RAM/แบตเตอรี่จริงในรอบนี้ ไม่รับรองว่าจอดับแล้วระบบ Android ทุกยี่ห้อจะรักษาบริการได้เสมอ ควรยืนยัน SOS คงอยู่ จอดับแล้วเชื่อมกลับ และส่งรูป/วิดีโอ/ตำแหน่งทั้งแบบไม่มีอินเทอร์เน็ตและสลับกลับออนไลน์

ให้อัปเดตทั้งสองฝั่งเป็นรุ่น 34 เพื่อได้ stable discovery hint เต็มรูปแบบ รุ่นเก่าที่ประกาศโดยไม่มี hint ยังอ่านชื่อได้ แต่ไม่สามารถรวม endpoint ที่ยังไม่ตรวจตัวตนอย่างปลอดภัยจากชื่ออย่างเดียว ความเร็วจริงขึ้นกับวิทยุ สัญญาณ ขนาดไฟล์ และการจำกัดเบื้องหลังของเครื่อง GPS ยังขึ้นกับสภาพรับดาวเทียม

ไม่มีการเปลี่ยน schema หรือ live Supabase รอบนี้ ข้อจำกัดก่อนเผยแพร่สาธารณะใน `docs/publishing-checklist-v31.md` ยังคงใช้
