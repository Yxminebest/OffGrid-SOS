# รุ่น 0.10.1+32 — ลดงานซ้ำและเก็บโค้ดที่ไม่ได้ใช้

## สิ่งที่เปลี่ยน

- หน้าหลัก/รายการแชท/ห้องสนทนาใช้ตัวติดตามกล่องแชทชุดเดียวกันต่อบัญชี พร้อมส่ง snapshot ล่าสุดให้ผู้ติดตามใหม่ ไม่เปิดการอ่านฐานข้อมูลซ้ำตามจำนวนหน้าจอ
- เมื่อผู้ติดตามสุดท้ายออก หยุด subscriptions และ debounce ทันที พร้อมปล่อย snapshot ในหน่วยความจำ การอ่านที่เริ่มแล้วอาจทำจนจบแต่จะไม่ส่งผลเข้าหน้าที่ปิดแล้ว
- รวมเหตุการณ์ฐานข้อมูลที่ติดกัน และไม่อ่าน inbox พร้อมกันหลายชุด กรองตารางตามเจ้าของบัญชี
- แปลงข้อความคลาวด์ครั้งเดียวต่อการอ่าน แล้วจัดกลุ่มตามห้อง แทนแปลงทุกข้อความซ้ำในแต่ละห้อง
- เริ่มแท็บ Nearby/แชท/โปรไฟล์เมื่อเปิดครั้งแรก ยังเก็บ state เมื่อสลับกลับ และบริการรับ SOS/แชทเริ่มแยกจากหน้าจอตามเดิม
- หน้าหลักวาดใหม่เฉพาะยอด unread เปลี่ยน และไม่ติดตาม inbox คลาวด์สำหรับ snackbar บน Android ที่มี native notifications อยู่แล้ว
- รายการแชทวาดใหม่ตาม topology ของผู้ติดต่อ แทนทุก event ความคืบหน้าไฟล์ รวมคำขอ refresh ที่ทำงานพร้อมกัน และใช้ cooldown ตรวจบัญชีที่ถูกลบ
- คิว unified chat ยังเริ่มทันทีเมื่อส่ง/เครือข่าย/เส้นทางเปลี่ยน เปลี่ยน fallback จากทุก 5 เป็น 15 วินาที และไม่อ่าน DB เมื่อไม่มีทั้งอินเทอร์เน็ตและเส้นทางวิทยุ การ retry ของ mesh และ SOS คงเดิม
- งานดาวน์โหลดสื่อสำหรับออฟไลน์อ่านเฉพาะ image/video ไม่ดึงข้อความธรรมดามาคัดทิ้งภายหลัง
- ลบไฟล์ไม่มีผู้เรียกใช้: conversation_screen.dart (wrapper เก่า), cloud_media_card.dart, status_badge.dart
- ลบ LocalDatabase.conversationIdFor, pendingSyncCount และ clearWeek3DemoData พร้อม import uuid ที่ไม่ใช้แล้ว ไม่มีการลบข้อมูลผู้ใช้จริง

## ขอบเขต

ไม่ล้างประวัติแชท คิว SOS ไฟล์สื่อ แผนที่ออฟไลน์ หรือข้อมูลบัญชี ไม่เปลี่ยน live Supabase หรือโปรโตคอลวิทยุ และไม่ลดความแม่นยำ GPS เพื่อแลกกับประสิทธิภาพ

รุ่นนี้แก้สาเหตุของงานซ้ำที่ตรวจพบและทดสอบการปล่อยทรัพยากร ยังไม่ได้วัด CPU/RAM/แบตเตอรี่/การส่งวิดีโอบนโทรศัพท์จริง จึงไม่รับรองตัวเลขความเร็วหรือการประหยัดแบตเตอรี่ APK รวม native libraries หลายสถาปัตยกรรมและแผนที่ที่จำเป็น การลบโค้ดที่ release tree-shaking ตัดอยู่แล้วไม่ได้ทำให้ APK เล็กลงมากเสมอไป
