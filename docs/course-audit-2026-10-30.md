## มีโค้ดแล้ว แต่ต้องทดสอบบนเครื่องจริง

**ทดสอบอย่างน้อย 2 เครื่อง:** ปิด mobile data และไม่ใช้ Wi-Fi access point/hotspot; เปิดแอปและสิทธิ์ที่จำเป็น; ส่งข้อความ, รูป, วิดีโอ และ SOS พร้อมพิกัดระหว่างเครื่อง; ตรวจสถานะผู้ช่วยเหลือ/ผู้ประสบภัยและการเปิดห้องสนทนา; ปิดอินเทอร์เน็ตแล้วเปิดกลับเพื่อดูคิวและ cloud sync

**ทดสอบ 3 เครื่องแบบต่อทอด:** ให้ A เชื่อมกับ B และ B เชื่อมกับ C โดยไม่มีลิงก์ A-C โดยตรง; ส่งข้อความ/SOS จาก A ให้ถึง C และทดสอบย้อนกลับ; ตรวจว่าการ relay ทำงานเมื่อ B เปิดแอปและอยู่ในระยะ แล้วบันทึกผลจริงและภาพหน้าจอ

ควรตรวจเพิ่มเรื่องสิทธิ์ Bluetooth/Nearby/ตำแหน่ง, GPS fix, การทำงานเมื่อจอล็อกหรือแอปอยู่เบื้องหลัง, การกลับมาเชื่อมต่อหลังสัญญาณหลุด และความเข้ากันได้ระหว่างรุ่นโทรศัพท์

ณ เวลาตรวจนี้ `adb devices` ติดต่อ ADB daemon ไม่สำเร็จ จึงไม่ได้รันการทดสอบวิทยุหรือบันทึกผลจากเครื่องจริงในรอบนี้

## เงื่อนไขและข้อจำกัดที่ควรแจ้ง

- Nearby P2P ที่ตรวจพบในโครงการเป็น Android; อย่าอ้างว่ารองรับ iOS โดยไม่มี implementation และผลทดสอบยืนยัน
- ต้องเปิดวิทยุและอนุญาตสิทธิ์ที่ Android ขอ; พิกัดต้องมีบริการตำแหน่งและได้ตำแหน่งที่ใช้ได้
- บัญชี Guest ใช้งาน local/offline ได้ แต่การซิงก์ cloud ต้องมีบัญชี/session ที่ใช้ได้; การสมัครหรือออก credential หน่วยกู้ภัยใหม่ต้องใช้อินเทอร์เน็ต
- การส่งต่อหลาย hop ที่มีในปัจจุบันขึ้นกับ relay B ที่ยังเปิดแอปและเชื่อมต่ออยู่; ยังไม่ใช่ store-and-forward ที่รับประกันการส่งต่อภายหลังเมื่อ B หายไป
- แผนที่/ข้อมูลพื้นที่มีขอบเขตตามข้อมูลที่เตรียมไว้ในโครงการ จึงไม่ควรสื่อว่าเป็นแผนที่นำทางครอบคลุมทุกพื้นที่
- APK ที่พบเป็น v0.8.2+20 สร้างเมื่อ 24 ต.ค. ขณะที่ source/tests บางส่วนเปลี่ยนวันที่ 28 ต.ค.; หากสาธิต APK ควร build และติดตั้งจาก source ล่าสุดก่อน
