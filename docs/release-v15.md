# รุ่น 0.6.1+15 — GPS และหน้าใช้งานจริง

วันที่ 24 ตุลาคม 2569

## พฤติกรรมใหม่

- นำหน้าทดสอบระยะ ปุ่ม และโปรโตคอล probe/reply ออกตามคำขอ ไม่เพิ่มแพ็กเก็ตทดสอบให้เครื่องอื่น ข้อมูลประวัติเดิมที่เคยทดสอบไม่มีหน้าใช้งานแล้วและยังลบพร้อมข้อมูลบัญชีได้
- หน้าหลักเน้น SOS และจุดเข้า Nearby / แชท / กู้ภัย / แผนที่ แก้ข้อความ Guest ให้ตรงว่าแชท Nearby ได้โดยไม่สมัคร
- Nearby แสดงขั้นตอนจับคู่ 3 ข้อขณะยังไม่เชื่อม หลังเชื่อมซ่อนคู่มือและแสดงความพร้อมใช้งาน สีเหลืองหลัก สีน้ำเงินเฉพาะโหมดกู้ภัยที่เปิด
- เปิดแอปใหม่เริ่มหน้าหลัก เมื่อกลับจาก paused จะกลับแท็บหน้าหลักและปิดเส้นทางย่อย กล้องและตัวเลือกไฟล์ใช้ guard เพื่อกลับไปงานเดิม หน้าขอสิทธิ์แบบ inactive ชั่วคราวไม่บังคับกลับหน้าแรก

## GPS และการส่งตำแหน่ง

- ใช้ bestForNavigation ขอพิกัดสูงสุดจากระบบ ไม่ต้องเรียก HTTP สำหรับ GPS หรือแผนที่
- แผนที่รอได้ 45 วินาที SOS/แชทรอได้ 30 วินาที หยุดก่อนเมื่อได้อย่างน้อย 3 ตัวอย่างคุณภาพไม่เกิน 10 เมตร กินช่วงเวลาอย่างน้อย 2 วินาที ค่านี้เป็นเกณฑ์เลือก ไม่ใช่คำรับประกันความแม่นยำจริง
- เลือกพิกัดจริงที่ค่าคลาดเคลื่อนต่ำสุดภายในหน้าต่าง 8 วินาที ไม่เฉลี่ยตัวเลขให้ดูดี ไม่ลดค่าคลาดเคลื่อนที่ระบบรายงาน ไม่เปลี่ยนเวลาเดิมเป็นเวลาปัจจุบัน และปล่อยหมุดตามเมื่อการเปลี่ยนตำแหน่งเกินผลรวมความคลาดเคลื่อน
- ถ้าไม่มี GPS สด ใช้ fallback ที่ระบุชัดว่า last-known; ไม่แอบใช้พิกัดเก่าเป็นพิกัดปัจจุบัน
- แผนที่อัปเดต GPS ขณะเปิดหน้าและหยุด stream เมื่อพักแอป/ออกจากหน้า ปุ่มกลับหมุดกลับตำแหน่งของฉันเมื่อมี GPS แล้ว
- แสดงเตือนเมื่อ GPS หยาบกว่า 30 เมตร พร้อมทางลัดสิทธิ์ตำแหน่ง หมุดผู้ส่งมีวงความคลาดเคลื่อนสีแดงเมื่อมี metadata; ตำแหน่งของฉันสีน้ำเงิน
- เพิ่มปุ่มอัปเดตพิกัด SOS เดิม บันทึก local DB เพิ่ม revision และส่งต่อ Nearby ไม่สร้างเหตุใหม่ ไม่เปิด SOS ที่หยุดแล้วกลับมา
- ตำแหน่งแชท Nearby แสดงความคลาดเคลื่อนก่อนยืนยันส่ง

## ตรวจและทดลอง

- ตรวจแผนที่ สว่าง/มืด จอเล็กและตัวอักษรใหญ่; ตรวจภาพหน้าหลัก/Nearby จาก widget rendering
- ทดสอบเลือก GPS 49 → 6 → 70 เมตรโดยคงค่าจริง, พิกัดขยับ/หมดอายุ/ไม่ถูกต้อง, deadline/cancellation, และเกณฑ์รับหลายตัวอย่าง
- ทดสอบ SOS เปลี่ยนพิกัดและ accuracy ส่งถึงอีกโหนดใน transport จำลอง เหตุที่ยกเลิกแล้วไม่กลับมา active
- ทดสอบ lifecycle กลับหน้าหลัก/ไม่ตัดกล้องและ picker; ไม่มีหน้าทดสอบระยะใน Nearby
- ต้องทดสอบวิทยุจริง 2–3 เครื่องและ GPS กลางแจ้งหลังติดตั้ง ไม่ใช้ผลจำลองอ้างระยะส่งหรือความแม่นยำหน้างาน
- ไม่มีการแก้ schema หรือ deploy Supabase ในรุ่นนี้
