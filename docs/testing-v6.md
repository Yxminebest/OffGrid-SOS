รูปหรือวิดีโอเก่าที่รุ่นก่อนเคยอัปโหลดแล้วล้างต้นฉบับออก **ต้องเปิดขณะออนไลน์เพื่อดาวน์โหลดใหม่หนึ่งครั้ง**
รุ่นนี้ไม่สามารถสร้างไฟล์ที่ไม่เคยมีในเครื่องกลับมาเองขณะไม่มี Internet
การดาวน์โหลดที่ไม่ครบไม่ถือเป็นไฟล์พร้อมเปิด; การเปิดซ้ำใช้ไฟล์ถาวร ไม่ต้องขอ signed URL อีก
แชท cloud บน web ยังใช้เส้นทางเดิม การเก็บไฟล์ถาวรในรุ่นนี้เป็นเส้นทาง native Android

## ตรวจด้วยโทรศัพท์เครื่องเดียว

1. ติดตั้งอัปเดตโดยไม่ถอนแอปเดิม เปิด Internet และเข้าห้อง cloud เดิม
2. รอรูปเก่าแสดงจริง และเปิดวิดีโอที่จะทดสอบจนไฟล์พร้อมเล่น
3. ปิด Wi-Fi/mobile data แล้วเปิดแอปใหม่ รูปและวิดีโอที่ดาวน์โหลดครบต้องยังเปิดได้
4. กด + → ถ่ายรูป ขณะ offline รูปใหม่ต้องแสดงจากเครื่องและขึ้นรอซิงก์คลาวด์
5. เปิด Internet อีกครั้ง รอให้ซิงก์คลาวด์แล้ว จากนั้นกลับ offline ตรวจว่ารูปใหม่ยังอยู่
6. แตะตำแหน่งในแชท/SOS ต้องเห็นแผงพิกัดในแอปและคัดลอกได้โดยไม่เปิด Google Maps
7. หากเลือกเปิดแอปแผนที่ ภาพแผนที่/เส้นทางยังขึ้นกับข้อมูล offline ของแอปแผนที่นั้น
8. ในประวัติ SOS ตรวจว่าปิด SOS ไม่ได้แปลว่าหน่วยกู้ภัยรับแล้ว และซิงก์แล้วไม่ได้แปลว่าช่วยเหลือสำเร็จ
9. เมื่อยังไม่มีคู่ Nearby ปุ่มเชื่อมต่อ Nearby ต้องไปหน้าจัดการอุปกรณ์ ไม่อ้างว่าส่งผ่าน Bluetooth ไปแล้ว

Cloud และ Nearby เป็นคนละประวัติ/คิว ยังไม่มีการรวมประวัติ Nearby ขึ้น cloud หรือ private multi-hop
การรับส่งจริงและแจ้งเตือนข้ามเครื่องยังต้องใช้ Galaxy และ Y33s ตามคู่มือรุ่น 5
ไม่มีการแก้ backend/schema หรือเปลี่ยนข้อมูลบัญชีในรอบนี้
