# Release 0.9.6+27 — SOS พร้อมค้นหาและส่งต่ออัตโนมัติ

## ปัญหาเดิมและผลหลังแก้

- GPS เดิมเริ่มหลังเปิด SOS แล้วรอเก็บตัวอย่างสูงสุด 30 วินาที: ตอนนี้เริ่มเตรียม GPS ระหว่างเปิดแอปอยู่ด้านหน้า นำค่าจริงที่เพิ่งวัดได้ใส่เคสตั้งแต่สร้าง และอ่านพิกัดล่าสุดของ Android พร้อมกับเริ่มรับ GPS สดโดยไม่รอกัน
- พิกัดแรกที่หาได้ส่งเข้าเคสและ Nearby ทันที แม้ความแม่นยำยังต่ำ จากนั้นปรับด้วยค่าที่ดีขึ้นในช่วง 35 วินาที ไม่แก้ตัวเลขความคลาดเคลื่อน ไม่สร้างพิกัดสมมติ พิกัดเก่าติดสถานะ last-known และไม่ทับพิกัดสด
- หาก GPS ตอบหลังหยุด SOS ธุรกรรมฐานข้อมูลปฏิเสธการแก้เคสที่หยุดแล้ว การออกจากหน้าจอยกเลิกตัวติดตาม และหยุดเตรียม GPS เมื่อแอปออกจากด้านหน้า
- เดิมต้องเข้า Nearby และกดเชื่อม/เทียบรหัสก่อน: ตอนนี้เปิดแอปแล้วเริ่ม Nearby โดยอัตโนมัติ เริ่มเชื่อมเมื่อค้นพบเครื่อง และรับการเชื่อมต่อของแอปโดยอัตโนมัติ มีการหน่วงต่างกันเล็กน้อยเพื่อลดการขอพร้อมกัน คุมจำนวนคำขอ และเว้นการลองซ้ำ
- รายชื่อจากการค้นพบวิทยุแสดงทันทีในหน้า SOS โดยไม่ต้องรอจับคู่ ไม่มีการนำประวัติคลาวด์มาอ้างว่าอยู่ใกล้เคียง
- กู้ภัยที่ตรวจใบรับรองผ่านและประกาศปฏิบัติหน้าที่อยู่จะแสดงแถบสีน้ำเงิน เรียงก่อนบุคคลทั่วไป แตะสนทนาได้หลังลิงก์พร้อม
- เมื่อเชื่อมสำเร็จใช้กลไกเดิมส่ง SOS ล่าสุดและพิกัดต่ออัตโนมัติ รวมการส่งต่อผ่านเครื่องตัวกลาง

## ข้อกำหนดการใช้งานจริง

ทั้งสอง/สามเครื่องควรติดตั้งรุ่น 27 เปิดแอป และอนุญาตตำแหน่ง/อุปกรณ์ใกล้เคียง เปิดวิทยุ Bluetooth และ Wi-Fi (ไม่ต้องเชื่อมเราเตอร์ ฮอตสปอต หรืออินเทอร์เน็ต) เครื่องรุ่นเก่าที่ยังต้องกดยืนยันต้องอัปเดตด้วย

GPS ที่ไม่เคยจับสัญญาณหรืออยู่ในอาคารยังอาจต้องรอสัญญาณดาวเทียม ไม่มีซอฟต์แวร์รับประกันพิกัดแม่นหรือค้นพบอุปกรณ์ได้ทันที การแก้ครั้งนี้ตัดการรอในแอปและเตรียมล่วงหน้า ไม่รับประกันเวลาจากฮาร์ดแวร์หรือ Android และไม่รับประกันรับข้อความเมื่อแอปถูกบังคับปิด

## การเชื่อมต่อและตัวตน

Nearby รับลิงก์อัตโนมัติแทนการเทียบ authentication token ด้วยมือ ตาม flow ที่ API รองรับ: https://developers.google.com/nearby/connections/android/manage-connections

การรับลิงก์อัตโนมัติไม่ใช่การยืนยันชื่อบุคคล กลไกตรวจใบรับรองกู้ภัย อายุใบรับรอง กุญแจที่บันทึกไว้ และการลงลายเซ็นในโปรโตคอลยังคงอยู่ สีน้ำเงินไม่ใช้เพียงชื่อหรือสถานะที่ประกาศตอนค้นพบ
