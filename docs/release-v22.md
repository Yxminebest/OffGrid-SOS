# 0.9.1+22 — SOS ด่วนจากหน้าแรก

31 ตุลาคม 2569

- เปลี่ยนการ์ดหน้าแรกเป็นปุ่ม SOS วงกลมสีแดงขนาด 184 logical pixels
- แตะครั้งเดียวบันทึกข้อความขอความช่วยเหลือทั่วไปใน local DB ไม่มี dialog หรือการบังคับพิมพ์
- เริ่มวิทยุ/ส่งต่อและหา GPS เบื้องหลัง เมื่อได้พิกัดใหม่อัปเดตเคสเดิม ไม่สร้าง SOS เพิ่ม
- การบันทึกสำเร็จไม่ใช่หลักฐานว่าปลายทางได้รับ: แสดงสถานะเชื่อมต่อและทางเปิดรายละเอียดแยกไว้
- ป้องกันการกดซ้ำระหว่างบันทึกและตรวจเคส active ก่อนสร้าง
- เมื่อ active ปุ่มวงกลมเปิดรายละเอียด พร้อมปุ่มเพิ่ม/แก้ไขและหยุด SOS แยกชัดเจน
- หยุดแล้ว GPS ที่มาภายหลังต้องไม่เปิด SOS กลับเอง
- แสดง SOS จาก inbox ที่ผ่านการรับของ mesh เหนือปุ่มวงกลม โดยใช้สถานะล่าสุดรวมการยกเลิก ไม่แสดงเคสของตัวเอง
- แสดงตัวอย่างหนึ่งคำขอพร้อมจำนวนทั้งหมด แตะผู้แจ้งเข้าห้องแชทรวม และมีทางดูทั้งหมดเมื่อหลายเคส
- ไม่มีการเปลี่ยนฐานข้อมูลคลาวด์หรือ protocol และยังต้องจับคู่ตามระบบเดิม ไม่อนุมัติคู่ใหม่โดยอัตโนมัติ
