# 0.9.0+21 — ปรับ UX สำหรับขอความช่วยเหลือ

31 ตุลาคม 2569

## การเปลี่ยนแปลง

- หน้าหลักจัดลำดับใหม่: ขอความช่วยเหลือ → สถานะเชื่อมต่อจริง → ข้อมูลซิงก์ → แชท/หน่วยกู้ภัย/แผนที่
- ปุ่มหลักเขียนว่า ขอความช่วยเหลือ SOS; เมื่อเปิดอยู่ใช้ข้อความดูสถานะ/หยุด ไม่สร้างความเข้าใจว่ากดปุ่มหน้าแรกแล้วส่งทันที
- ลดความสูงข้อความแนะนำและปรับการ์ด SOS ให้กระชับ สถานะ active ใช้พื้นสีแดงเข้ม
- แสดงจำนวนอุปกรณ์ที่เชื่อมต่อจริงผ่าน listener ของ Nearby ไม่ใช้สถานะ cloud แทนการยืนยันว่ามีผู้รับ SOS
- เมื่อยังไม่เชื่อมต่อ บอกว่า SOS บันทึกในเครื่องได้แต่ต้องเชื่อมต่อเพื่อส่งถึงผู้อื่น พร้อมปุ่มเข้าหน้าค้นหาอุปกรณ์
- แยกคำเรียกศูนย์กู้ภัยสำหรับผู้มีสิทธิ์ออกจากการขอสิทธิ์ของสมาชิกทั่วไป
- หน้า SOS ลดข้อความซ้ำ เพิ่มพื้นที่แตะตัวเลือกเหตุ และคงการเลือกหลายเหตุได้โดยไม่ใช้คีย์บอร์ด
- หน้ายืนยันแสดงเหตุที่เลือกมาแล้วโดยไม่ต้องเลือกชุดเดิมซ้ำ; แก้ไข SOS/เปิดโดยยังไม่เลือกเหตุยังเลือกใน dialog ได้
- คงสถานะปุ่ม SOS/กู้ภัยด้านบนตามที่ผู้ใช้กำหนด ไม่มีปุ่มสลับธีมบนหน้าหลัก
- ไม่เปลี่ยน protocol วิทยุ ฐานข้อมูล และสิทธิ์บน Supabase; รวมค่าตั้งค่า Supabase รุ่น 20
