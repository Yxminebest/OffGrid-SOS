## ทดสอบบนเครื่องหลังอัปเดต

1. ปิด mobile data และตัดการเชื่อม Wi-Fi hotspot/router เปิดแอปจากหน้าล่าสุดที่ปิดไปแล้ว
2. หน้าแรก → แผนที่ปทุมธานี ต้องเห็นถนนและชื่อไทยทันทีโดยไม่ต้องโหลดข้อมูลเพิ่มเติม
3. เปิด GPS/อนุญาตตำแหน่ง กดหาตำแหน่งในที่โล่ง ตรวจหมุดและเวลาความคลาดเคลื่อน
4. ส่งพิกัดผ่าน Nearby ไปอีกเครื่อง แตะพิกัด ต้องเปิดหมุดแดงในแผนที่ภายในแอป ไม่มีการเปิด Google Maps
5. ปิด GPS แล้วลองหาใหม่ ต้องมีปุ่มเปิดการตั้งค่าและไม่อ้างพิกัดเก่าเป็นพิกัดปัจจุบัน
6. ทดสอบซูม/เลื่อน/กลับไปยังหมุด เปลี่ยนสว่าง/มืด และตัวอักษรใหญ่

ข้อมูลเป็นแผนที่ถนน ไม่ใช่ระบบนำทางเลี้ยวต่อเลี้ยว และไม่มีข้อมูลจราจร/ถนนถูกตัดขาดแบบสด ขอบเขตและใบอนุญาตดู assets/maps/pathum_thani/README.md
