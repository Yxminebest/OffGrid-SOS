## รันบน Android

ตั้งค่า Publishable Key ของโปรเจกต์ Supabase ก่อนรัน:

```sh
flutter pub get
flutter run --dart-define=SUPABASE_PUBLISHABLE_KEY=YOUR_KEY
```

ใช้ `--dart-define=SUPABASE_URL=YOUR_PROJECT_URL` เมื่อต้องการเปลี่ยนโปรเจกต์
และตั้งค่า redirect URL `com.kittaporn.offgridsos://login-callback/` ใน Supabase Auth

## การใช้งาน

หน้าจอรองรับโหมดสว่างและโหมดมืด เปลี่ยนได้จากปุ่มดวงจันทร์/ดวงอาทิตย์
บนหน้าเข้าสู่ระบบและหน้าแรก หรือที่ **โปรไฟล์ → รูปแบบการแสดงผล**
แอปจำรูปแบบที่เลือกไว้เมื่อเปิดครั้งถัดไป หน้าแรกแสดงสถานะ SOS ที่ยังทำงาน
ส่วนหน้า Nearby แสดงอุปกรณ์และสถานะการเชื่อมต่อจริง ข้อความ Nearby อยู่ในแท็บแชท

1. เข้าสู่ระบบสมาชิก หรือเลือก Guest เพื่อบันทึก SOS ในเครื่อง
2. เปิด SOS เลือกเหตุฉุกเฉินได้หลายข้อ เช่น ติดอยู่บนหลังคา/ขาดน้ำมาก/ต้องการยา/มีผู้ป่วยหนัก แล้วกดยืนยัน ไม่จำเป็นต้องพิมพ์ เพิ่มรายละเอียดเองได้ แอปบันทึกพิกัดพร้อมเวลาที่อ่านพิกัดได้
3. เปิด Nearby บน Android ทั้งสองเครื่อง แล้วเชื่อมต่อและยืนยันรหัสตรงกัน
4. บัญชีหน่วยกู้ภัยที่ผ่านการอนุมัติสามารถเปิด RESCUE รับ SOS และแชทผ่าน Nearby

เมื่อเริ่ม Nearby จะขอสิทธิ์ Android: ตำแหน่งขณะใช้งานแอป,
Bluetooth บน Android 12 ขึ้นไป และอุปกรณ์ Wi-Fi ใกล้เคียงบน Android 13 ขึ้นไป
หากปฏิเสธถาวร ให้ใช้ปุ่มเปิด Settings ในหน้า Nearby แล้วกดเริ่มอีกครั้ง
ต้องเปิดบริการตำแหน่งของ Android เพื่อใช้งาน Nearby สำหรับกรณีปิดวิทยุ Wi-Fi
มีปุ่ม **ใช้ Bluetooth เมื่อปิด Wi-Fi** เลือกโทรศัพท์ที่จับคู่ในตั้งค่า Bluetooth แล้ว
เปิดรับ Bluetooth ในแอปทั้งคู่ จากนั้นให้เครื่องใดเครื่องหนึ่งเลือกเชื่อมต่อ

SOS ที่ยัง active และรหัสอุปกรณ์แยกตามผู้ใช้จะถูกกู้คืนเมื่อเปิดแอปใหม่
กดเริ่ม Nearby และจับคู่ใหม่เพื่อประกาศ SOS ต่อ สถานะยกเลิก SOS ถูกส่งซ้ำด้วยเลข revision
ข้อความส่วนตัว Nearby เก็บถาวรแยกตามผู้ใช้ มีคิวรอส่งและการตอบรับระดับแอป
ส่งตรงถึงเครื่องที่จับคู่เท่านั้น ไม่ส่งข้อความส่วนตัวผ่านอุปกรณ์ตัวกลาง
SOS สาธารณะยังส่งต่อแบบ best-effort ได้ตาม TTL

ในห้องแชทกด **+ → ถ่ายรูป** เพื่อเปิดกล้อง หรือเลือกรูป/วิดีโอจากเครื่อง
ห้อง Nearby ส่งไฟล์ถึงอุปกรณ์ที่จับคู่โดยตรงทั้งกรณีมีและไม่มีอินเทอร์เน็ต
ถ้าปิด Wi-Fi ให้ใช้การเชื่อม Bluetooth ตามขั้นตอนข้างต้น โดยเปิด Bluetooth ทั้งคู่
ไฟล์ถูกคัดลอกออกจาก camera cache ไปเก็บในพื้นที่ส่วนตัวของแอปก่อนเข้าคิว
รับครบและตรวจ SHA-256 แล้วจึงยืนยันว่ารับถึงเครื่อง เปิดรูป/เล่นวิดีโอจากไฟล์ในเครื่องได้
กล้องมีการกู้คืนผลเมื่อ Android ปิด Activity ระหว่างถ่าย โดยผูกกับบัญชีและห้องเดิม
ห้อง cloud มีปุ่ม Bluetooth สำหรับเลือกห้อง Nearby ของสมาชิกที่จับคู่แล้วโดยตรง

แอปขอสิทธิ์แจ้งเตือนบน Android 13+ จัดการได้ที่ **โปรไฟล์ → การแจ้งเตือนข้อความ**
และ **รับข้อความเบื้องหลัง** มี foreground service พร้อมแถบสถานะและ shared Flutter engine
เพื่อรับข้อความขณะออกจากหน้าจอแอป บริการนี้ไม่ใช่ FCM push ที่ปลุกโปรเซสใหม่
หากบังคับหยุดหรือระบบประหยัดแบตเตอรี่ฆ่าโปรเซส ต้องเปิดแอปและเชื่อมต่ออีกครั้ง
ควรทดสอบการกด Home, ปัดออกจากหน้าล่าสุด และปิดหน้าจอบนโทรศัพท์ทั้งสองรุ่น

ตำแหน่งใน SOS/แชทใช้ปุ่ม **เปิดตำแหน่งบนแผนที่** เปิดหมุดภายในแอป
กดไอคอนเข็มทิศเพื่อคำนวณระยะเส้นตรงและทิศทางจาก GPS ได้โดยไม่ใช้อินเทอร์เน็ต
รุ่น 12 มีภาพถนนปทุมธานีจากฐานข้อมูลเวกเตอร์ใน APK แล้ว (783 ไทล์ ~8.7 MB) ไม่ต้องใช้เน็ตหรือเคยเปิดแผนที่มาก่อน
เปิดภาพรวมได้จากหน้าแรก → **แผนที่ปทุมธานี** กด **หาตำแหน่งของฉัน (GPS)** เพื่อแสดงหมุดของคุณและวงความคลาดเคลื่อน
หมุดแดงเป็นพิกัดที่รับมา หมุด GPS สีน้ำเงินคือพิกัดปัจจุบัน/สีเทาคือพิกัดเก่าพร้อมเวลา หาก GPS ปิดหรือสิทธิ์ถูกปฏิเสธมีปุ่มเข้าตั้งค่า
ชุดข้อมูลจำกัดกรอบปทุมธานีและขอบใกล้เคียง พิกัดนอกพื้นที่ยังอ่าน/คัดลอกได้ แต่ไม่มีภาพถนนทั่วประเทศไทยหรือระบบนำทางเลี้ยวต่อเลี้ยว
ห้อง cloud แสดงสถานะรอซิงก์คลาวด์/ซิงก์คลาวด์แล้ว แยกจากการยืนยันรับของ Nearby
รูปและวิดีโอ cloud ที่เก่าและไม่มีในเครื่อง ต้องเปิดขณะออนไลน์เพื่อดาวน์โหลดครบก่อนดู offline

ข้อมูลสมาชิกที่ส่งไม่สำเร็จจะอยู่ในคิว และลองใหม่อัตโนมัติขณะบริการแอปทำงาน
ตามช่วงรอ 5, 15, 30, 60 และ 300 วินาที โดยตรวจงานที่ครบกำหนดทุก 5 วินาที
การออกจากระบบหยุด Nearby ล้างสถานะในหน่วยความจำ และหยุดบริการซิงก์
ข้อมูล SOS และคิวในเครื่องยังอยู่สำหรับบัญชีเดิม

อยู่ที่ `assets/branding/offgrid-icon.png` ส่วนตัววาดในแอปอยู่ที่

สร้าง PNG ทุกความละเอียดใหม่จากตัววาดเดียวกับ UI ได้ด้วย:

```sh
flutter test tool/export_brand_test.dart
```

Android ใช้ adaptive icon และมี monochrome icon สำหรับธีมของระบบ
หน้าจอเริ่มต้นรองรับโหมดสว่างและมืดของเครื่อง ไฟล์เวกเตอร์ของ Android อยู่ใน
`android/app/src/main/res/drawable/ic_launcher_foreground.xml` และ `ic_brand.xml`

## ตรวจสอบการทำงาน

```sh
flutter analyze --no-pub
flutter test --no-pub
flutter build apk --debug --no-pub
```

ชุดทดสอบใช้ฐานข้อมูลในหน่วยความจำและเซิร์ฟเวอร์จำลองในเครื่อง
ครอบคลุมการแก้ไข/ยกเลิกระหว่างซิงก์ การลองใหม่ การกู้คืน SOS การเปลี่ยนบัญชี
และการเลือกสิทธิ์ตาม Android SDK ยังต้องทดสอบวิทยุ Nearby ด้วย Android จริงสองเครื่อง

คู่มือรุ่น 0.3.0+5 อยู่ที่ `docs/testing-v5.md` ทั้งสองเครื่องต้องอัปเดตเป็นรุ่นเดียวกัน
